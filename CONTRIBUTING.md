# Contributing to AI Compliance Command Center

## Branch Naming
Always create a new branch for your work. Never push directly to `main`.

| Type | Format | Example |
|------|--------|---------|
| Deliverable work | `epic/deliverable-name` | `epic/ai-innovation-map` |
| Documentation | `docs/description` | `docs/governance-framework` |
| Diagrams | `diagrams/description` | `diagrams/workflow-architecture` |
| Fix or update | `fix/description` | `fix/readme-update` |

## Commit Messages
Keep commit messages clear and descriptive.

```
✅  Add AI use case register draft
✅  Update workflow architecture diagram v2
✅  Fix broken links in README
❌  update
❌  changes
❌  misc
```

## Pull Requests
- All work goes through a Pull Request before merging into `main`
- Add a short description of what you changed and why
- Tag at least one team member to review

## File Naming
- Use lowercase and hyphens, no spaces
- Example: `ai-innovation-map-v1.md` not `AI Innovation Map V1.md`

## Folder Guide
| Folder | What goes here |
|--------|---------------|
| `docs/ai-innovation-map/` | Strategy documents, opportunity matrices, use case registers |
| `docs/workflow-architecture/` | Workflow docs, integration registers, tech stack docs |
| `docs/governance-model/` | RACI matrix, governance frameworks, policy documents |
| `docs/prompt-library/` | All prompt templates and registers |
| `diagrams/` | Exported Miro boards, architecture diagrams, flowcharts |
| `presentations/` | Executive deck drafts and final presentation files |
| `demos/` | Prototype files, demo scripts, mock dashboards |

## Questions?
Reach out to the team on our group chat or tag someone in a GitHub issue.
